Period (around 2012) site icons for link cards, one `<name>.png` per entry in `RetroIcons.swift`.

For now the app uses the sites' own 2012 favicons, saved from the Internet Archive and copied
here by hand. Those files are other companies' artwork, so they are gitignored and a fresh
checkout has none; a missing file simply means the card shows the site's current icon.

The plan is to replace them with icons drawn for this app, using the originals as references.
